# RobotinaIA

## Visión

RobotinaIA será un asistente inteligente de inversión que permitirá al usuario monitorear mercados financieros, administrar su portafolio, analizar activos mediante indicadores técnicos y recibir recomendaciones fundamentadas.

---

## Objetivo del MVP

La primera versión deberá permitir:

1. Consultar el precio de una acción.
2. Registrar compras.
3. Calcular rentabilidad.
4. Analizar técnicamente una acción.
5. Generar una recomendación:
   - Comprar
   - Mantener
   - Vender

---

## Principios del proyecto

- Arquitectura limpia.
- Código desacoplado.
- Desarrollo incremental.
- Pruebas automáticas.
- Documentación continua.
- Un Sprint = Una funcionalidad terminada.

---

## Objetivo a largo plazo

Convertir RobotinaIA en un asistente profesional para inversiones con soporte para:

- Bolsa de Valores de Colombia (BVC).
- Acciones internacionales.
- ETFs.
- Criptomonedas.
- Portafolios.
- Noticias.
- Inteligencia Artificial.
- Alertas automáticas.
- Dashboard profesional.
