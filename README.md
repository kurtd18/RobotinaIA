# 🤖 RobotinaIA

## Descripción

RobotinaIA es un asistente inteligente para inversiones diseñado para analizar mercados financieros, administrar portafolios y generar recomendaciones utilizando Inteligencia Artificial.

---

## Objetivos

- Monitorear la Bolsa de Valores de Colombia (BVC).
- Monitorear ETFs y acciones internacionales.
- Administrar portafolios.
- Calcular indicadores técnicos.
- Analizar noticias financieras.
- Generar recomendaciones mediante IA.
- Enviar alertas automáticas.

---

## Tecnologías

- Python 3.12
- Git
- PySide6
- PostgreSQL
- SQLAlchemy
- Plotly
- Pandas
- OpenAI
